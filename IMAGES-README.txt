AL-AMEEN IMAGE GUIDE
====================
Photos live in these folders. To swap a photo, replace the file and keep the same name.
Every card photo is 4:3 (for example 1200x900). The hero is 16:9 (1280x720 or larger).
Use JPG or WebP under 400 KB (compress at squoosh.app). Use photos you own or have
permission to use. A missing file shows a dark panel with an icon, so nothing breaks.
